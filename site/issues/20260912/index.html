把关系重新做一遍：本周 10 个文化坐标

20260912

关系并不只发生在恋人之间。它也藏在一家人如何熬过难关、陌生人怎样共享一条街、创作者如何把一支乐队、一场远征、一次漫长的告别组织成共同经验里。这个秋天，值得把“我和世界的距离”从抽象感受，重新放回具体的人、声音与空间。

本期从三本关于爱、家庭与相处的书出发，穿过三部电影里的家庭现场；再把耳朵交给一张仍在生长的摇滚专辑，把时间交给一部关于告别的动画，把行动交给一场游戏远征，最后去南京的梧桐和城墙之间走一段。它们都不承诺立刻解决问题，只邀请我们练习更认真地看见彼此。

01 / 书页之间

书页之间

《许三观卖血记》｜余华

作品档案｜出版：2012｜豆瓣：9.2（205,895 人评价）｜类型：小说 / 家庭 / 中国当代文学

豆瓣条目：https://book.douban.com/subject/4760224/

余华把极重的命运写进极轻的口语里。许三观一次次卖血，故事却不靠苦难的堆叠取胜：饭桌、闲话、误会和一次次硬撑，才是这个家庭真正的经纬。幽默在这里不是减轻疼痛，而是让人看见人在逼仄处仍会互相逗笑、互相给台阶。

今天重读它，尤其适合抵抗一种把家庭叙事写成“情绪正确”的冲动。爱并不总以体面方式出现；它常常是笨拙的补偿、迟到的理解和不肯离席。小说把这种不完美保留下来，也让“照顾”重新有了体温。

提示：包含疾病、贫困与暴力处境描写。

《爱的艺术》｜艾里希·弗洛姆

作品档案｜出版：2008｜豆瓣：8.8（57,351 人评价）｜类型：心理学 / 哲学 / 社会学

豆瓣条目：https://book.douban.com/subject/3026879/

这本小书最有力量的地方，是拒绝把爱当作“遇见对的人”之后自然发生的事。弗洛姆把关怀、责任、尊重和了解并置，把爱从一种强烈感受还原成长期能力；读来像一份不太温柔、却很清醒的练习题。

它的年代感与局限同样值得带着读：书中部分性别论述已显陈旧，不能照单全收。但正因如此，更能分辨其中仍然锋利的核心——关系不能替代自我成长，也不能用占有来证明亲近。适合在“沟通技巧”泛滥的当下，回到更慢的自我提问。

提示：部分性别与亲密关系观点有时代局限，建议批判性阅读。

《亲密关系》｜罗兰·米勒、丹尼尔·珀尔曼

作品档案｜出版：2011｜豆瓣：9.0（19,555 人评价）｜类型：心理学 / 社会关系 / 科普

豆瓣条目：https://book.douban.com/subject/5952488/

它把常被短视频切成碎片的关系议题，重新放回研究、样本和概念之中：吸引、依恋、冲突、承诺、权力，都是会在具体互动里变化的过程。读它的好处，不是得到一张“如何经营”的清单，而是获得更准确的语言，去描述自己究竟卡在何处。

和《爱的艺术》搭配看，会有一种有趣的张力：前者强调爱的伦理和人格，后者提醒我们关系也受情境、资源与习惯影响。把这两种视角同时留下，或许比急于给任何一段关系下结论更有用。

提示：学术框架较多，可按章节选择阅读。

02 / 银幕之上

银幕之上

《婚姻故事》｜诺亚·鲍姆巴赫

作品档案｜上映：2019｜豆瓣：8.6（301,143 人评价）｜类型：剧情 / 爱情 / 家庭

豆瓣条目：https://movie.douban.com/subject/27202818/

这部片最残酷的不是争吵，而是它让两个人都足够可理解。剪辑把谈判、探视和失控的争执排得像不断收紧的绳结；表演则让每句伤人的话都带着“我原本想被你听见”的余音。它不把离婚拍成谁胜谁负，而是拍成语言失效之后，程序如何接管亲密。

此刻看它，仍会被那个看似朴素的判断刺中：一段关系的结束并不抹掉其中曾有的爱。它特别适合和本期的书一起看——当我们谈“沟通”，也要承认沟通并非总能挽回，但它至少能让告别少一些互相否定。

提示：含高强度争执与离异议题。

《如父如子》｜是枝裕和

作品档案｜上映：2013｜豆瓣：8.7（182,895 人评价）｜类型：剧情 / 家庭

豆瓣条目：https://movie.douban.com/subject/10571509/

一个抱错孩子的设定，本可以被拍成密集的伦理剧；是枝裕和却始终把镜头放在生活的缝隙里：谁陪孩子洗澡，谁愿意蹲下来一起玩，谁把工作节奏强加给家庭。电影用两种父亲、一组居住空间和许多沉默的停顿，慢慢拆开“血缘”“成功”“陪伴”之间被默认的等号。

它今天依然珍贵，是因为没有替观众选边站。父亲并不是一个天然完成的身份，而是一组要在时间里兑现的行动。对于忙着证明自己合格的大人而言，这部片提供的不是答案，而是一次克制的减速。

提示：涉及儿童、家庭伦理与情绪压力。

《摩登时代》｜查理·卓别林｜影史补课

作品档案｜上映：1936｜豆瓣：9.3（336,524 人评价）｜类型：剧情 / 喜剧 / 爱情

豆瓣条目：https://movie.douban.com/subject/1294371/

卓别林把流水线拍成了一架会吞人的喜剧机器：齿轮、传送带和规定动作都精确得可笑，人却在精确里越来越慌乱。最厉害的是，他从不让批判压扁喜剧；身体的失控、道具的反叛、配乐的节拍，让劳动异化有了可以被看见、也可以被笑出来的形状。

作为本期影史补课位，它与今天的算法节奏并不遥远。片中流浪汉和女孩彼此扶持的结尾，给出的不是宏大救赎，而是两个人继续往前走的姿态。关系有时不能改变机器，却能让人不被机器完全定义。

提示：黑白默片节奏与时代背景需要一点耐心进入。

03 / 唱针与耳机

唱针与耳机

《万能青年旅店》｜万能青年旅店

作品档案｜发行：2010｜豆瓣：9.5（99,148 人评价）｜类型：摇滚 / 独立音乐 / 中国摇滚

豆瓣条目：https://music.douban.com/subject/5344708/

这张专辑的乐器从不只是在“伴奏”。小号、手风琴、吉他和鼓把北方工业城市的灰尘、河流和夜路织成了可行走的地形；旋律明明有摇滚的推进力，转弯时却总留下一块空地，让词里的失业、迁徙和欲望能在里面回声。

十五年后再听，它仍像一部没有镜头的城市电影。那些具体的地名和人物没有被怀旧封存，反而不断提醒我们：共同生活的重量，往往先被写进一个街区的声响里。建议完整顺序听，不必急着把每一句都解释成结论。

提示：建议留出完整专辑时长聆听。

04 / 动画放映室

动画放映室

《葬送的芙莉莲》｜斋藤圭一郎

作品档案｜上映：2023｜豆瓣：9.4（118,077 人评价）｜类型：动画 / 奇幻 / 冒险

豆瓣条目：https://movie.douban.com/subject/36093351/

它从传统冒险故事最容易跳过的地方开始：魔王已经被击败，庆功之后，伙伴开始老去。芙莉莲漫长的寿命让她起初不懂人类为何珍惜短暂；动画便用散步、做饭、整理遗物和重走旧路这些小事，让“理解”不再是一句宣言，而是一点点补上的时间。

高口碑之外，它真正适合本期的，是对关系节奏的耐心。人物不靠一次长谈完成和解，情感也不会立即转化为答案；背景、配乐和留白共同让观众明白，记住一个人并不是停留在过去，而是把过去带进新的行动。

提示：节奏舒缓，含死亡与告别主题。

05 / 游戏时间

游戏时间

《光与影：33号远征队》｜Sandfall Interactive

游戏档案｜发售：2025｜口碑：Steam 96% 好评（102,456 条评测）｜类型：角色扮演 / 回合制 / 奇幻

官方页面：https://store.steampowered.com/app/1903340/Clair_Obscur_Expedition_33/

它把回合制战斗做成一种需要共同呼吸的节拍：格挡、闪避和技能衔接都要求你在敌方动作里读出时机；队伍构筑又迫使角色彼此补位。于是“远征”不是地图上的任务标记，而是一群人在明知有限的时间里，怎样把能力和信任交给彼此。

对中文玩家而言，官方页面已标注简体中文支持，足以作为安心进入的入口。更值得慢慢体会的是它的叙事：作品把死亡倒计时设为世界规则，却不把人物写成纯粹的牺牲符号。每次继续前进，都是在问“留下些什么给后来的人”。

提示：含战斗、血腥、自杀意象与较高操作门槛；建议避开剧透。

06 / 城市漫游

城市漫游

南京｜城墙、梧桐与街区慢行

城市档案｜推荐季：2026 秋｜核验：官方文旅 / 公共交通｜类型：城市漫游

目的地信息：https://english.nanjing.gov.cn/LivinginNanjing/Transportation/

南京适合本期，不是因为它能提供一条必须打卡的线路，而是因为它让不同时间尺度很容易并置：城墙的厚度、梧桐的阴影、大学周边的书店和旧街区的日常，都提醒人城市并不只靠地标组成。秋天不妨把目的地缩小：先选一段城墙或一处街区，再允许自己在路上改变方向。

官方信息将地铁、公共自行车与巴士服务放在同一份抵达说明里，正好支持一种低负担的慢行方案。把地铁当作连接点，而不是赶场工具：白天在鼓楼、玄武湖或老城边缘步行，傍晚再回到一条可直达的线路。城市最好的部分，往往出现在不必证明“来过”的空档。

提示：秋季昼夜温差与周末人流较大；出发前请查看官方文旅和南京地铁的实时安排。

07 / 结尾：把关系留在具体处

结尾：把关系留在具体处

本期的十个位置并不要求你一次全部完成。读一本书、看一部电影、听完一张专辑，或在周末走一段不赶时间的路，都足以让关系从概念回到身体和日常。我们不必总追着新的内容跑；更难也更有用的，是在旧问题里练习新的看法。

愿这个秋天，我们既保留独处的空间，也不放弃认真靠近的能力。
